### The code: a predicate with no direction test, and what a skipped read leaves behind

**The predicate never tests direction.** It reads the owner from the buffer's memory. xfs/xfs_mxfs_buf.c:1031-1103 holds no XBF_READ or XBF_WRITE test anywhere:

- :1056-1057 `	owner = be64_to_cpu(((struct xfs_btree_block *)` / `			     bp->b_addr)->bb_u.l.bb_owner);`
- :1069-1070 `	if (ip && ip->i_ino == owner && S_ISDIR(VFS_I(ip)->i_mode)) {` / `		if (ip->i_dlm_mode == MXFS_LOCK_NL) {`
- :1073 `		} else if (bp->b_tenure_id != ip->i_mxfs_ex_grant_seq) {`

**The skip arm stales the buffer and completes the bio with no I/O.**
- pal/linux/xfs_buf.c:9692-9693 `	if (mxfs_buf_xfsaild_skip_bmbt_write(bp) &&` / `	    mxfs_bmbt_chokepoint_covers(bp)) {`
- :9695 `		mxfs_bmbt_skip_preserve_truth(bp, "chokepoint");`
- In that function, :8799 `	if (same == 0) {` leads to :8812 `		xfs_buf_stale(bp);`
- Then :9726-9727 `		xfs_buf_ioend(bp);` / `		return;`

**A read's completion sets XBF_DONE.**
- :3664 `	if (bp->b_flags & XBF_READ) {`
- :3828-3829 `		if (!bp->b_error)` / `			bp->b_flags |= XBF_DONE;`

**A cache lookup cannot hand out a stale buffer.** It resets one:
- :1068 `	if (bp->b_flags & XBF_STALE) {`
- :1096 `		bp->b_flags &= _XBF_KMEM;`

**P975 prints the buffer's flags before the buffer is marked corrupt.**
- xfs/libxfs/xfs_btree.c:1978 `		mxfs_bmbt_lookup_bad_probe(cur->bc_mp, bp,` comes before :1982 `	xfs_buf_mark_corrupt(bp);`
- xfs/xfs_mxfs_dir_bmbt.c:2189 `		be32_to_cpu(cb->bb_magic), bp->b_flags,`

**Decoding the flags.**
- xfs/xfs_buf.h:29 `#define XBF_READ	 (1u << 0) /* buffer intended for reading from device */`
- :31 `#define XBF_READ_AHEAD	 (1u << 2) /* asynchronous read-ahead */`
- :32 `#define XBF_ASYNC	 (1u << 4) /* initiator will not wait for completion */`
- :33 `#define XBF_DONE	 (1u << 5) /* all pages in the buffer uptodate */`
- :34 `#define XBF_STALE	 (1u << 6) /* buffer has been staled, do not find it */`
- So `flags=0x1` is a plain synchronous read, `flags=0x15` a readahead, and `flags=0x60` DONE|STALE.

**What this proves.** A refused lookup with flags=0x60 was handed a buffer that was staled inside its own read and completed as read. That is the predicate's path.
