## Verdict: REJECT

The batch itself meets every verify condition (Checks 1-6 below). The proposal is rejected because
its argument says the batch graded things it did not grade, and one of those is the contract-argument
branch that the rejection of P20261023-7bd24f asked to have graded or dropped from the claim:

1. **The contract argument was never exercised.** The argument says the lap reads "target_retire_contract (the contract argument whose quoting the rejection named)". That presents the
   contract quoting as answered. It was not. On this rig the contract is NONE, so `c` is empty and
   `${c:+ 'target_retire_contract=\"$c\"'}` adds nothing to the rejoin's argv. Both nodes read the
   parameter as the empty string in every lap. An empty-against-empty comparison passes whatever the
   quoting does. The "Not covered and not claimed" list leaves this branch out.
2. **The argument contradicts the control's own measurement.** It says "with none set the victim
   and survivors agree at the defaults whatever the rejoin loads and nothing is measured". Every
   control lap also failed on `log_repeat_limit=1 (survivor 0)`. That argument is not part of
   MXFS_EXTRA_MODARGS, so the pre-fix rejoin is detected with no extra arguments set at all.
3. **The "mixed windows" consequence was not reproduced on this candidate.** It does not say so. The
   candidate's module defaults to a 12 s window on SCSI, so the control's victim, loaded with
   `dead_timeout_ms=0`, still ran a 12000 ms death window, the same as the survivors. The batch
   measures the dropped arguments, which is the record's cause. It does not measure a lane running
   mixed effective windows. A removal that relies on this batch must not claim otherwise.

The batch is sound. A new proposal that cites the same batch can be approved if its argument is
corrected on all three points: (1) the contract branch is listed as not exercised (prep reported
NONE, and both nodes read `target_retire_contract=` empty); (2) the `log_repeat_limit` statement
matches what the control measured; (3) it states that the control's effective window equalled the
survivors' on this candidate, and that what was verified is that the argument values now match.
